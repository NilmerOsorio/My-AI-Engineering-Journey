# 🚀 Project 01: Modern Dark/Light Mode Welcome Page

Welcome to the first project in my **AI Agent Engineering Journey**! 

This project is a clean, modern, single-page web application featuring responsive styling and a interactive dark/light mode theme toggle. Rather than writing all the boilerplate manually, I directed an **autonomous AI coding agent** to scaffold, structure, and refactor the codebase.

---

## 🤖 AI Agent & Workflow Metadata

Transparency is key when building with AI! Here are the details of the agent configuration used to create this project:

* **Agent CLI Tool:** [OpenCode](https://opencode.ai) (`v2.1.4`)
* **AI Model:** `Big Pickle` *(OpenCode Default Reasoning Model)*
* **Execution Mode:** `Build`
* **Key Agent Capabilities Demonstrated:**
  * 📁 **Automated Project Restructuring:** The agent created separate folders (`styles/` and `js/`) and extracted inline code into dedicated files.
  * 🔗 **Asset Linking:** Cleanly updated HTML tags (`<link>` and `<script>`) to connect external resources.
  * 🎨 **UI & Logic Implementation:** Wrote responsive CSS styling and vanilla JavaScript theme-switching logic.

## 📁 Project Architecture

```text
project-01-html-darkmode/
```

## ✨ Features

* 🌙 **Dark & Light Mode:** Seamless theme switching with a single button click.
* 📱 **Responsive Card Layout:** Clean hero section centered in a modern container with subtle background gradients.
* ⚡ **Modular Code Structure:** HTML structure, CSS styling, and JavaScript logic are neatly decoupled across dedicated folders.
