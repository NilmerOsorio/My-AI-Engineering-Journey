# 🎮 Project 03 — Rock, Paper, Scissors

A modern, responsive **Rock, Paper, Scissors** web application built with vanilla HTML, CSS, and JavaScript. Play against the computer with live score tracking, winning streaks, smooth animations, and a polished dark theme! 🚀

---

## ✨ Features

- 🤖 **Player vs. Computer:** Classic game rules with random computer moves.
- 🎯 **Interactive UI:** Clickable buttons with glowing hover effects & animations.
- 📊 **Live Score Tracking:** Separate counters for player wins, ties, and computer wins.
- 🔥 **Winning Streak:** Tracks consecutive victories, resetting on losses and persisting through ties.
- 📱 **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.
- 🌌 **Modern Dark Theme:** Gradient backgrounds, glassmorphism cards, and glowing accents.

---

## 🛠️ Tech Stack

- 🌐 **HTML5** — Semantic markup & structure.
- 🎨 **CSS3** — Custom properties, animations, Flexbox, & Grid.
- ⚡ **Vanilla JavaScript** — State management, game logic, & DOM manipulation.

## 🕹️ How to Play

1. ✊ Click **Rock**, **Paper**, or **Scissors** to make your move.
2. 🤖 The computer randomly selects its counter-move.
3. 🏆 View the round result, live scores, and active winning streak.
4. 🔄 Click **Reset Game** anytime to start fresh!
